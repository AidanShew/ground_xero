PROJECT OVERVIEW
Far From Eden is a 2D, vertically scrolling bullet hell.
This personal project lets me gain hands-on experience with object-oriented programming while in school.

PROJECT SUMMARY
Engine:				GameMaker Studio
Language:			GML
Version Control:	Git/GitHub
Architecture:		Object-Based, modular functions "Scripts"
Data Structures:	Arrays, enums, structs, functions
Gameplay:			State-based enemy behavior, timers, pre-set movement 
Project Scope:		Far From Eden - Mission One
